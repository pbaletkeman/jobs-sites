# Remote Jobs

A curated list of remote job boards and career sites organized alphabetically.

## Overview

This project provides a comprehensive list of companies and platforms that post remote job opportunities. Each entry includes the site name and a link to their careers page.

## Structure

The list is organized alphabetically from 0-9, A-Z. Each section contains sites starting with the corresponding letter.

| Section | Letters |
|---------|---------|
| 0 - 9 | Digits |

| B | B |

## Adding New Sites

To add a new site, simply add a new entry to the appropriate alphabetical section in `jobs.md` following the existing format:

```markdown
| Site Name | URL |
| --- | --- |
| [Site Display Name](https://example.com) | https://example.com |
```
